Annotation policy and how to use this page

Include private patient/participant and provider names, patient-linked places, explicit current or historical ages, contact/record identifiers, and explicit patient-linked calendar dates. Keep ordinary medicines, symptoms, measurements, amounts, treatment/disease durations, relative time words, software terms, and generic honorifics visible. Public football commentary is outside this proposed privacy policy. Confirm that policy with the dataset owner.

Select the exact identifier in the original text and click Add selected span. Use PERSON, AGE, ADDRESS, MEDICAL_ID, PHONE_NUMBER, EMAIL, sensitive_date, date_of_birth, username, or password as appropriate. Unfamiliar names can still be names; a name list is not required. Mark every occurrence. Do not invent corrected spellings, full phone numbers, dates, or identities from unclear speech.

Read the full text before completing a row. The optional suggestions are assistant labels, not verified answers. Resolve any uncertainty using fluent-language review or source audio. If a row contains no in-policy PII after exhaustive review, complete it with an empty annotation list. Each completed row records your human sign-off; do not use this control for unexamined data.

This page works locally and sends no data anywhere. Work is held in this tab until you save a progress file. Save before closing. Only a complete set of reviewed rows can be exported as reviewed ground truth.
